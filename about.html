What It Is Now

VidChat is currently a static PeerJS video room that can be hosted on GitHub Pages. It creates a random room ID, puts that ID in a copyable link, and lets multiple people join the same peer-to-peer room from that link.

The current app supports camera sharing, screen sharing, optional screen-share audio, per-feed audio volume controls, and video tiles that can be moved and resized inside the call area. Layout buttons arrange the visible feeds, but each feed can also be adjusted manually.

Future Enhancement

A future version could turn the underlying PeerJS behavior into reusable vanilla JavaScript web components. That is not what the app currently exposes.

The earlier component idea included a global window.vidChatMe Peer object, persisted peer IDs, PeerMedia components for peer video and screen streams, PeerChat components for persistent text chat, and a global window.vidChatPeers object for tracking connections.

That component toolkit would be useful if VidChat becomes a library for building custom PeerJS apps. For now, VidChat is an end-user room app rather than a reusable web-component API.
